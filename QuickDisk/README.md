# QuickDisk 0.4.3

Нативный анализатор занятого места для macOS 14+. Проект написан на SwiftUI по наблюдаемому поведению SquirrelDisk; код и ресурсы SquirrelDisk не копировались.

Универсальная сборка 0.4.3 поддерживает Apple Silicon (`arm64`) и Intel (`x86_64`). Требуется macOS 14 или новее.

В настройках можно включить или отключить файловый кэш и выбрать папку для его хранения. При отключённом кэше приложение не читает и не создаёт крупные файлы снимков; каждый запуск начинает сканирование заново. Ранее созданные файлы не удаляются. Кэш содержит имена и метаданные, но не содержимое файлов. При включённом автоматическом обновлении сохранённый снимок показывается сразу и запускается фоновый полный перескан для синхронизации. Кэш отображается по уровням: сначала корень и первые 500 крупных элементов папки; следующие партии подгружаются по запросу.

При просмотре кэша список показывает загруженную партию; кнопка «Показать ещё» подгружает следующую. Фильтры и выбранный порядок применяются к загруженным элементам.

В окне «Изменения» кнопка «Сохранить снимок» запускает свежий скан и записывает точку истории с датой завершения. Автоматическое сохранение истории после обычных сканов можно включить в настройках. Хранится до 365 последних записей для каждого пути; полное дерево повторно не копируется. Файлы снимков и кэша размещаются в одной выбранной папке. Если приложение закрыто, фоновое сканирование не выполняется. Когда между сохранёнными снимками были сканы без записи истории, программа отмечает сравнение файлов как неполное. Системная разница — приблизительная оценка и может включать снимки APFS, служебные и недоступные данные.

В версии 0.4.1 добавлено удаление отдельной записи истории после подтверждения; файлы на диске при этом не затрагиваются. В версии 0.4.2 индикатор сканирования использует анимацию волн из демо DemFinal. По центру показываются процент и счётчик файлов; процент оценивается по общему числу файлов предыдущего скана или кэша. При первом сканировании, когда знаменатель неизвестен, отображается «…%», а после завершения — 100%. В версии 0.4.3 в настройках можно выбрать между «Цветными волнами» DemFinal и чёрно-белым Veil Crossing из оригинального Metal-шейдера DemFinal-Fork2 / 64K. Veil Crossing появляется полностью сразу, без вступительного затухания, и остаётся видимым всё время сканирования. Кнопка «Изменения» активна сразу после запуска и открывает историю последнего недавнего сканирования; при нескольких источниках можно выбрать нужный.

Во время активного сеанса автоматическое обновление применяет события файловой системы только к изменённым путям и сохраняет неизменённые поддеревья. При удалении перечитывается родительская папка, чтобы восстановить учёт оставшихся жёстких ссылок. При потере событий macOS выполняется полный перескан. Кнопка повтора также запускает полный скан.

Обновление папки перечитывает её список элементов и сканирует содержимое только новых вложенных каталогов. Событие для файла обновляет его метаданные и суммы родителей. Если macOS сообщает о потерянных событиях файловой системы, QuickDisk выполняет полный повторный скан для восстановления целостности дерева.

## Запуск

Запустите `./build.sh`, чтобы собрать универсальное приложение рядом с этой папкой (`../QuickDisk.app`), затем откройте его двойным щелчком. Приложение собирается для Apple Silicon (`arm64`) и Intel (`x86_64`), подписывается локально ad hoc и не нотариализуется Apple.

1. Выберите диск или папку; папку можно перетащить в окно.
2. Дождитесь завершения сканирования. Во время обхода отображаются предварительная диаграмма, число файлов и объём; полный результат доступен после завершения.
3. Нажмите сегмент папки или дважды щёлкните строку, чтобы войти в папку. Нажмите центр диаграммы для возврата к родителю; кнопки вверху перемещают по истории.
   Хлебные крошки открывают любой родительский уровень. `⌘[` и `⌘]` перемещают назад и вперёд, `⌘R` запускает полный повторный скан.
4. Поиск ищет по имени во всём текущем поддереве. Фильтры ограничивают тип и минимальный размер; сортировка — размер, имя или дата.
5. Контекстное меню файла позволяет показать его в Finder, открыть системный предпросмотр и скопировать путь.
6. «Дубликаты» сравнивает текущий локальный результат и дополнительные папки по полному SHA‑256. Показаны пути всех копий и размер повторных файлов. Копии не выбираются автоматически.
7. «Экспорт PDF» сохраняет одностраничную сводку с диаграммой текущей папки, карточками основных показателей и шестью самыми крупными элементами из отфильтрованного списка. Для каждого показаны выделенный и логический размеры.

По просьбе пользователя в проекте отсутствуют удаление, перемещение, очистка, рекламные блоки и плиточная диаграмма. Доступен только кольцевой вид.

Приложение работает в App Sandbox. Сканер имеет read-only security-scoped закладку для выбранной папки; экспорт сохраняет PDF в место, которое пользователь отдельно выбирает в системном диалоге сохранения. Повторный скан из «Недавних» после перезапуска прошёл без нового системного запроса. При первом выборе расположения macOS всё равно требует выбора/разрешения; это требование нельзя отключить из приложения. QuickDisk не запрашивает Full Disk Access и не обходит системную защиту. Для тома без сохранённой закладки кнопка «Сканировать» открывает системный выбор папки.

## Безопасность данных и приватность

Сканер читает метаданные. Для дубликатов читает содержимое файлов. Пользовательские файлы не изменяются. Приложение сохраняет настройки, до восьми последних путей сканирования, кэш метаданных (если он включён) и выбранные пользователем отчёты. При отключённом кэше снимки дерева не читаются и не записываются; экспорт PDF сохраняется только по запросу. Нет телеметрии, регистрации, рекламы и автоматического обращения к серверу обновлений.

Ссылки не обходятся; жёсткие ссылки и повторные inode учитываются один раз. Подключённые файловые системы обходятся отдельным сканированием, чтобы не уйти на другой том. Для `/` дополнительно учитывается том данных APFS, повторный обход `/System/Volumes/Data` исключается. Объекты с системным флагом SF_DATALESS (включая не загруженные облачные файлы) учитываются как 0 выделенных блоков и не хешируются.

Системный предпросмотр выполняется через Quick Look; показ в Finder — средствами macOS. Из программы нельзя удалить файл. Вспомогательные команды удаляют только собственные временные файлы логов; самопроверка — только созданную ею временную папку.

## SSH и облака

SSH использует системный `/usr/bin/ssh`, существующие ключи/агент и known_hosts, с BatchMode и StrictHostKeyChecking. Ввод пароля и подтверждение нового ключа в приложении не поддерживаются. На сервере необходим Python 3. Передаётся только команда чтения дерева; дополнительный агент на сервер не устанавливается. Необходимо явно запустить сканирование в диалоге подключения.

Для облака нужен установленный и настроенный отдельно rclone. Обнаруживаются `/opt/homebrew/bin/rclone`, `/usr/local/bin/rclone`, `/usr/bin/rclone` и `/bin/rclone`. Пример источника: `drive:Projects`. Используется `rclone lsjson --recursive`; показываются размеры объектов из ответа сервиса, а не локально выделенное место. Авторизация выполняется существующей конфигурацией rclone. Интерфейс подключения проверен по коду; реальные серверы и облачные аккаунты в этой сессии не использовались.

Удалённые результаты доступны для навигации, фильтрации и PDF-экспорта; Finder, предпросмотр и сравнение дубликатов относятся к локальным данным.

## Командная строка и самопроверка

```sh
./.build/release/QuickDisk --self-test
./.build/release/QuickDisk scan /path/to/folder --depth 2 --top 15
./.build/release/QuickDisk scan /path/to/folder --json
```

Команды предназначены для локального исполняемого файла сборки. Упакованная GUI-версия ограничена пользовательскими разрешениями App Sandbox и читает выбранные папки через системный диалог.

## Сборка

Нужны Xcode/Swift 5.9+ и macOS SDK. Внешних зависимостей нет.

```sh
./build.sh
```

По умолчанию скрипт собирает универсальное release-приложение и подписывает ad hoc. Для Developer ID подписи задайте `DEVELOPER_ID_APPLICATION="Developer ID Application: ..." ./build.sh`; подписанная сборка использует hardened runtime и timestamp. Секреты в проект не записываются.

Для нотариализации после Developer ID подписи создайте профиль `notarytool` в Keychain и выполните `NOTARY_PROFILE=<имя-профиля> ./Tools/notarize.sh ../QuickDisk.app`. Скрипт отправляет архив, дожидается результата, прикрепляет билет и создаёт ZIP с SHA-256. Нужны действующие Apple Developer ID сертификат и профиль учётных данных; без них нотариализация не выполняется. В этой сборке она не запускалась.

## Проверки

```sh
./.build-arm64/arm64-apple-macosx/release/QuickDisk --self-test
```

Самопроверка создаёт временные папки и проверяет суммы размеров, hardlink, символические ссылки, SHA‑256-дубликаты, отмену сканирования, удалённое дерево, переименование и обновления файлов, бинарный кэш и ленивую подгрузку страниц. CLI JSON дополнительно проверен внешним разбором JSON.

В интерфейсе проверены запуск, выбор папки, кольцевая диаграмма, навигация по списку, поиск и обнаружение подготовленного дубликата. Для 0.2.0 сохранён скриншот корневого диска `../QuickDisk-preview-v02.png`.

В 0.2.1 палитра диаграммы обновлена по наблюдаемому визуальному принципу SquirrelDisk: крупные папки получают различимые цветовые семейства, вложенные сектора сохраняют оттенок своей верхней папки и меняют яркость по глубине. Заливка секторов плоская, границы тёмные и отчётливые. Свободное место и оценка скрытой занятой области показаны нейтральным серым. Это визуальное соответствие по наблюдению и публичному старому D3-источнику, а не утверждение о точном алгоритме текущей версии SquirrelDisk.

В 0.2.2 добавлен плавный градиент между близкими оттенками внутри каждого сектора. При наведении курсор меняется на указатель; выбранный сектор получает светлую подсветку и контрастную границу. Цвета и яркость остальных секторов при этом не меняются.

В 0.2.3 убрано поле поиска по текущему дереву и добавлен экспорт PDF.

В 0.2.4 PDF переработан в одностраничную сводку: кольцевая диаграмма, четыре карточки показателей и цветные полосы для шести крупнейших элементов. Диаграмма выводится в большом фиксированном холсте без обрезки.

## Ограничения версии

Это рабочая начальная версия, а не подтверждённая полная совместимость со всеми функциями SquirrelDisk.

- Размеры — суммы выделенных блоков `stat`, без измерения уникального места APFS-клонов, снимков и всех видов сжатия. Они могут отличаться от Finder и системной сводки.
- Ошибки доступа отображаются отдельно (сохраняются первые 200). Программа не запрашивает административные права и не выдаёт себе Full Disk Access.
- Во время обхода диаграмма предварительная: до трёх уровней и до ста дочерних узлов на папку и суммарно 1200 узлов. Остальные объёмы объединяются в предварительный сегмент. Итоговое дерево содержит все доступные объекты. Тонкие сегменты меньше порога не рисуются, но доступны в списке.
- Сканер пакетно читает метаданные macOS, распределяет блокировки inode и ограничивает предварительную диаграмму крупнейшими элементами. На томах без поддержки пакетного API используется запасной путь. Узлы хранят имя и ссылку на родителя; кэшированное дерево загружается партиями, хотя полный новый скан по-прежнему собирает все найденные узлы в памяти.
- Отслеживание изменений FSEvents отключено по умолчанию. При включении файлы обновляются по конкретным событиям, а папки перечитывают свой список и сканируют только новые вложенные каталоги; неизменённые поддеревья сохраняются из готового дерева. При потере событий macOS выполняется полный повторный скан.
- SSH требует Python 3 и готовую авторизацию. rclone устанавливается и настраивается отдельно. Потоковая диаграмма и дубликаты удалённых файлов пока не реализованы.
- Сетевой вывод временно сохраняется на этом Mac и удаляется после разбора. Очень большие удалённые каталоги могут потребовать много памяти и места для временного результата.
- Нет автоматического обновления, интеграции в меню Finder, полного набора тем/языков оригинала. Интерфейс на русском.
- Сборка протестирована только на текущем Apple Silicon Mac; публичная подпись, нотариализация и проверка других систем ещё не выполнены.

## Структура

- `Core.swift`: модель дерева, сканер, хеширование и поиск дубликатов.
- `Model.swift`: состояние интерфейса, фоновые задачи, история и FSEvents.
- `Charts.swift`: кольцевая диаграмма и выбор сегментов.
- `Main.swift`: главный экран, навигация, поиск, фильтры, Finder/Quick Look.
- `Panels.swift`: настройки, SSH/rclone и результаты дубликатов.
- `Remote.swift`: безопасная передача аргументов и разбор удалённых деревьев.
- `CLI.swift`: просмотр через терминал и встроенные проверки.
- `Tools/Icon.swift`: собственный программно нарисованный значок.

## Контрольный полный обход на этом Mac

На этом Mac один замер `/System/Library` дал 258 337 файлов за 3,27 с в 0.2.8 после пакетного чтения атрибутов; сравнимый замер 0.2.6 дал 258 335 файлов за 6,48 с. Разница в несколько файлов возможна из-за изменений дерева между запусками. Это один замер, не контролируемый бенчмарк. Полный системный обход ранее занимал около 28 с на 1,1 млн элементов.

Сводка тома показывает свободное место; для корня тома внешний сектор диаграммы разбивает ёмкость на просканированные объекты, свободное и скрытое занятое пространство. Последнее оценивается как занятое место тома минус сумма найденных файлов и может включать снимки APFS, служебные и недоступные данные; это не точная классификация скрытого пространства.
